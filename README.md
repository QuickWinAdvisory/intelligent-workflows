# Intelligent Workflows

Practical, AI-powered workflows from QuickWin Advisory. Each one is small, self-contained, and built so you can open one tool and get the job done without repeating context or copying data between apps.

| Workflow | What it is |
|---|---|
| [Kontrol Panel](kontrol-panel/) | A one-page start-of-day hub that runs as a Claude artifact: what needs attention today from Calendar and Gmail, a planner, a job-hunt pipeline with resume match and tailoring, and a product Kanban board. |
